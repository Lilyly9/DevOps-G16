## Reply to prompt-error-driven.txt

Here is the repaired Dockerfile. The build log shows `/bin/sh: 1: make: not found` at the `RUN make` step, so the `python:3.13-slim` base image lacks GNU Make and a C toolchain. I install `make`, `gcc` and the C standard library headers before the build step, keeping the pinned FROM digest, WORKDIR, COPY, `RUN make` and `CMD` exactly as in the failed Dockerfile:

```dockerfile
FROM python:3.13-slim@sha256:70729b46c69b4f1e97c4822c1af3df53a1476cf5ddc6c087c0c10bc3a5678c2f
WORKDIR /work
COPY main.c Makefile ./
RUN apt-get update && apt-get install -y --no-install-recommends make gcc libc6-dev \
    && rm -rf /var/lib/apt/lists/*
RUN make
CMD ["./hello"]
```
