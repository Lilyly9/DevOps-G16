# B2 ADR：最终重检通过后才保留候选声明

日期：2026-11-22；状态：本地实现，待 PR 审查。

原流程在沙箱验证通过时就写回候选 Makefile，而最终检测异常只结束任务，没有撤销声明。仅处理“仍有 MD”的正常报告不足以覆盖检测器执行失败。

采用一个覆盖验证和最终重检的事务边界：进入时保存原字节；最终报告没有 MD 时提交；任何其他退出均恢复原字节并写入独立回滚证据。沙箱验证结果与最终回滚结果分开保留，避免将“沙箱验证通过”误读为“整个修复已完成”。

没有采用 Git reset / clean：目标副本可能有与补丁无关的文件，任务只需恢复被发布的 Makefile。现有隔离验证也只将候选 Makefile写回源目标，头文件变更仍留在沙箱。

本次恢复范围仅为 Makefile，不提供对任意外部命令修改整个目录的通用事务。10 项个人契约覆盖拒绝、异常、超时、缺失文件、正确提交及失败后再尝试；真实 Docker 和四容器验收另留实际证据。
