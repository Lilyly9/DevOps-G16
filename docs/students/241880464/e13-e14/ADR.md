# ADR：E13/E14 交接与证据门禁

状态：实现已合入 main，提交为 `fa96f184760f1927621104542454450988e2eef0`。

A 侧交出的增量报告由 B 侧按提交、来源任务和字节摘要验收。旧 E11-B 入口先校验传输字节，等 DRAFT 完成后再读同一路径。两次读取会使实际消费和原件记录失去可核对性。E14 原工作流只扫描合并后的日志，缺一份单独角色日志时仍可能得到绿色结果。

保留原有入口和 C7 检查。E11-B 用同一次读取所得的信封消费报告，并保留原字节。内层提交核对仍在 DRAFT 后执行，以保留旧样例的阶段归因。工作流逐份检查角色日志同时校验镜像元数据，E14 独立核验五阶段关联、产物摘要、补丁及最终发现。只有扫描和验证均通过才上传 CI 工作目录。

C6 回归覆盖假 Key 脱敏和清理、正常日志与空或二进制输入混合的情况。课程固定样例用于 CI 回归，真实项目和教师发放项目各自保留云端运行。整组门禁、发布回退和标签由对应角色与组长按实际证据判定。
