# AI 使用记录

期末这一轮使用 Codex 辅助阅读课程要求，定位既有项目的 Git 输入，编写观测脚本、Compose 配置和验证脚本，通过 A16 云机执行实验，下载原始结果，生成报告草稿及演示手册。辅助代理只读复核了接口、提交版本和补丁验证路径。

实验证据来自实际运行。教师客户端核验了 E12 五阶段。另用脚本复算产物 SHA256 和字节数，核对候选镜像 ID、错误补丁拒绝前后的 Git 状态、三阶段终态与监控数据。原始文件和校验见 [实验记录](README.md)。

正式提交前由组员分别填写实际完成的人工复核、改动和演练记录。当前材料将云机执行和脚本核验记为 AI 辅助完成，组员个人复现实操由各自运行原件证明。

AI 辅助将运行入口改为可在不同个人工作区复验，并核验待提交文件与原始证据的对应关系。
